02 — featured project · hardware

metroboard

a real-time mta map — one led at a time.

i repurposed a subway map, installed an led at every station, and soldered 400+ joints by hand. an esp32 talks to a raspberry pi server pulling live mta gtfs-rt feeds, so each station flashes the color of the train arriving there in real time. i built an offline demonstration mode so it still runs when the network drops at a presentation.
