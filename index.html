project 01 · hardware

metroboard

a real-time mta map — one led at a time.

131 ws2812b leds wired across a plywood manhattan. an arduino nano esp32 pulls live gtfs-rt feeds from a raspberry pi running mtapi over websocket, so every addressable pixel lights up exactly where a train actually is — color-coded by line, updating in real time. i built an offline demo mode so it still runs when the network drops at a presentation.
